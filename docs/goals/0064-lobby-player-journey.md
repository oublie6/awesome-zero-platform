## 范围

## 交付

1. 可单元测试的状态→操作投影，不为未验证会员房间提供写入按钮。
2. Cocos 三座位信息、精简主操作与“更多”菜单；公平贡献和终局验证的输入目标隔离。
3. Vue 不再暴露重复的房间 create/join/recover 用户入口。
4. 静态/类型/单元/现有客户端 CI；独立 Cocos 真正渲染、触摸/会话/恢复验收由后续 Codex 执行。

## 本轮限制

当前无通用跨房间历史牌局分页查询接口；不伪造“历史对局”列表，不声称完成独立洗牌全量重算。目标是交互减法，不是删掉旧局恢复、账号关联或公平性保护。所有代码在 main 完成、提交与 CI 通过后才交给 Codex；Kubernetes 现有已验收版本保持不变。
